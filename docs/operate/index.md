# Run it

For Opencast admins running Management UI for other people. Afterwards you'll know which page covers the step you're on.

You need shell access to an Opencast host and the ability to restart or hot-deploy it.

## Tasks

- [Install](./install.md) — prerequisites, the bundles, and getting them into Opencast.
- [Configure](./configure.md) — `config.json`: branding, locale, enabled plugins, authentication.
- [Backend configuration](./backend-config.md) — the server-side settings, including whether "delete" means trash or gone.
- [Upgrade](./upgrade.md) — moving a deployment to a newer version.

## Look it up

- [Troubleshooting](./troubleshooting.md) — symptoms, causes, fixes.

Just evaluating? The [Quickstart](../quickstart.md) points a local dev server at an existing Opencast and installs nothing on the server.
