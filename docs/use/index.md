# Use it

For everyone who works with recordings in Management UI — editors, lecturers, support staff. Afterwards you'll know which page answers the task in front of you.

No setup knowledge needed: someone has deployed the UI, you have a link and an account.

## Tasks

- [The interface in five minutes](./tour.md) — what each part of the screen is for.
- [Find a video](./find-a-video.md) — search, sort, columns, paging.
- [Edit metadata](./edit-metadata.md) — change a recording's title, date, and other fields.
- [Upload a video](./upload.md) — add new material and see what happens to it.
- [Work with series](./series.md) — create a series and manage what belongs to it.
- [Delete a video](./delete-a-video.md) — the trash versus permanent removal.

## Look it up

- [Status reference](./status-reference.md) — what each processing status means and what it blocks.
- [Field reference](./field-reference.md) — every video and series field, spelled out.
